# Lab 3：NLP 与 LLM Agent

这次实验包含文本分类、检索问答和 LLM 游戏 Agent。前半部分从朴素贝叶斯和 TF-IDF 这些传统方法开始，之后又用词向量和 Attention 做文本分类。

## Part 1：文本分类与问答

### 朴素贝叶斯

我先统计正负样本中的词频，再计算一段文本属于两个类别的概率。

实现时主要处理了两个问题：

- 用拉普拉斯平滑避免某个词没出现过时概率直接变成 0；
- 用对数把很多概率的乘法变成加法，避免数值太小。

预测时还会加入正负样本本身的比例作为先验概率。虽然朴素贝叶斯的假设比较强，但代码很直观，也方便检查每个词怎样影响最后的分类。

### 词向量和 Attention

Embedding 会把每个词转换成 100 维向量。句子太长就截断，太短则补零，最后得到固定长度的输入。

网络结构是：

```text
Embedding
→ Attention → ReLU → LayerNorm
→ ResLinear → ReLU → LayerNorm
→ Mean Pooling
→ Linear → LogSoftmax
```

Attention 会根据句子中不同词之间的关系更新表示，最后对整段序列取平均，再完成分类。

### TF-IDF 问答

问答分两步：

1. 根据查询词的 TF-IDF 分数找到最相关的文档；
2. 在这篇文档中寻找匹配词 IDF 总和最高的句子。

如果两个句子的分数相同，再比较查询词在句子中所占的比例。这个方法不会自己生成新答案，而是从原文中返回最相关的一句，因此结果比较容易解释。

这部分代码本身不长，但 prompt 里的状态必须写清楚，模型返回的结果也需要限制在合法动作中。仓库里没有上传 API Key，只保留了不含密钥的主要作答代码。

## 这次实验的收获

把几种方法放在一起之后，我对 NLP 方法的发展更容易理解了：朴素贝叶斯直接统计词频，TF-IDF 用词的重要程度做检索，Attention 学习上下文关系，而 LLM 可以直接处理更复杂的文字描述。不过 LLM 接进程序以后，仍然需要处理输入格式、输出限制和错误情况。
