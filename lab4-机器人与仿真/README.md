### Q1:定位
用PPT中的蒙特卡洛定位思路进行设计即可
我学习[前人思路](https://github.com/BillWang3760/Introduction-to-Artificial-Intelligence-Labs-PKU-2025spring)，重新设计了is_valid_particle函数并引入了超参数COLLISION_DISTANCE,避免严格碰撞检测造成较大时间开销
同时，在重采样时，可以选择*将粒子总数乘以每个粒子的权重，并在每个粒子周围采样该数量的点，剩余的位置用均匀采样补全粒子总数*，也可以选择*用轮盘赌的方式，先按权重从大到小排序，求权重的前缀和，每次在0-1中均匀采样⼀个值，在前缀和数组中找到对应位置，该位置就对应着这次采样出来的粒子*；在取最终结果时，可以*求平均值*，也可以*直接取权重最大的*。建议排列组合试一下多种方式
